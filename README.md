# Employee Overview Dashboard

Interactive Excel dashboard to analyze employee data.

## Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)

## Key Insights
- Total Employees: 2000
- Average Salary: $72,500
- Promotion Eligible: 60%

## Features
- Filters: Department, Location, Status, Experience
- Department vs Salary chart
- Location vs Department analysis
- Promotion eligibility donut chart
